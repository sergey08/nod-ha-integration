# Changelog

## 1.0.0

### English

Release 1.0.0 of the Home Assistant integration works with Nod upstream 0.10.3. The verified app set is Server `0.1.0-dev.35`, Browser `0.1.0-dev.7` and Workspace `0.1.0-dev.7`.

- Guided setup or adoption of an existing server, with access through Home Assistant Ingress.
- Coordinated app updates with a verified local backup, exact version checks and recovery after an interruption.
- The maintainer confirmed installation and automatic startup on VMware and Lenovo. The isolated Lenovo setup also verified ChatGPT Plus sign-in and Google Docs document creation.

### Español

La versión 1.0.0 de la integración de Home Assistant funciona con Nod upstream 0.10.3. Las versiones verificadas de las aplicaciones son Server `0.1.0-dev.35`, Browser `0.1.0-dev.7` y Workspace `0.1.0-dev.7`.

- Instalación guiada o adopción de un servidor existente, con acceso mediante Ingress de Home Assistant.
- Actualización coordinada de las aplicaciones con copia local verificada, comprobación de versiones exactas y reanudación tras una interrupción.
- El mantenedor confirmó la instalación y el arranque automático en VMware y Lenovo. En el entorno aislado del Lenovo también se verificó el inicio de sesión con ChatGPT Plus y la creación de un documento en Google Docs.
